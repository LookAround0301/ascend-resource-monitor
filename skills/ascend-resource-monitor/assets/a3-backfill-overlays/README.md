# A3 short-backfill site overlays

The main runtime implements opt-in short backfill. These two overlays record the additional changes deployed to the existing A3 site-specific runtimes on 2026-11-10. They are provided because those sites contain local customizations that are not represented by the generic runtime: 101/103 has Russian/Moscow display, a 02:00/03:00 Beijing ordinary-task boundary and read-only container control; 139/140 retains its own node configuration and night-handoff policy. The A5 10:00 night cutoff and one-hour ordinary-task limit were not enabled on either A3 deployment.

Each patch applies to the four runtime files at the *old* SHA-256 values in the corresponding JSON manifest and produces the *new* values. It is not a general-purpose upgrade patch: do not apply it to a different version or overwrite cluster configuration. Review the site configuration, current reservations and night-handoff state, and take a consistent SQLite backup before deployment. Do not restore a database snapshot over subsequent reservations or sessions.

Run `python apply.py 103 /path/to/runtime-copy` (or `140`) against a copy of the matching runtime directory. The helper verifies the original hashes, applies the patch, normalizes recorded line endings and verifies the candidate hashes; it restores the copy if application fails. It does not deploy or restart services. Verify both nodes and 16-card capacity, the queue API and service health after a reviewed deployment. On 101/103, verify that container control remains disabled and the Russian/Moscow interface remains available.
